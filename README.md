# Carthago C2-tourer 3D-Stauraum-Manager 🚐

Interaktiver Stauraum-Manager für den **Carthago C2-tourer I 148 RB-QB „L“ comfort 4.2 t**.

Links eine dateisystem-ähnliche Liste aller Fächer, in der Mitte ein interaktives 3D-Modell des Wohnmobils. Ein Klick auf ein Fach öffnet unten eine Leiste mit dem aktuellen Inhalt. Gegenstände lassen sich per Dialog hinzufügen – entweder aus einer Auswahl vorgefertigter Standard-Items mit Symbolen oder als Freitext.

> 🔧 Aktueller Status: Planungsphase. Die Website wird erst nach Abstimmung der Planung gebaut.

- Tailwind CSS für das UI
- LocalStorage für lokale Daten (später optional Backend)
